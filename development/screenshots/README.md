# IndianOS development desktop screenshots

Only screenshots generated by actual IndianOS QEMU/OVMF test runs belong in
this folder. **Never put concept renders or mockups here.**

The CI workflow `.github/workflows/desktop-screenshot-history.yml` runs
whenever relevant UI source files change on `main`. It also supports manually
capturing a historical commit. Each successful capture boots a real guest,
verifies the Files/Terminal ring-3 graphics surface update, converts four
QEMU framebuffer screendumps to PNG without changing their pixels, and adds
a versioned directory:

`development/screenshots/<release-or-commit>-<exact-source-sha-prefix>/`

The folder contains `00-kernel-owned-desktop.png`,
`01-user-surface.png`, `02-user-surface.png`, `03-user-surface.png`,
and `metadata.json` identifying the source SHA, workflow SHA, Action run,
pixel hashes, and capture time.

`latest.png` is the latest visually distinct archived final frame.
A versioned archive folder is retained for every captured UI-changing commit,
even if its pixels did not change. It must not be labeled a new visual design
unless there is a demonstrated pixel difference.

Automatic archival pushes screenshots to main when allowed; if branch rules
block it, the workflow opens a screenshot-only PR. Every run also uploads a
90-day Actions artifact as a reliable fallback.

- Integration source: `eca69bcf2d3413b1517d7263dc4bfde02f665d56`

- QEMU image capture is a separate run and should not be claimed complete until
